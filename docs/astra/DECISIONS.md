| D-35 | **The app stays in its own chrome document (iframe), and its first paint is gated + repainted.** An in-tree mount into `browser.xhtml` was implemented and rejected the same day: the app's stylesheets are authored for its own document (`#root`, `html`, `body` scoping), so injecting them into the browser window broke the address field, tab labels and wordmark. Keeping the packaged document preserves that scoping. The visible-flicker cause was a compositor detail, not data: a chrome iframe caches the layer it painted while transparent, so revealing it showed a half-built frame. The loader keeps the frame at `opacity:0` (layout stays live so the app can measure and settle) and on the app's `ready` sets opacity and invalidates both layers (element transform + child `documentElement` opacity). | Decided 2026-11-03 (owner: "appeared, disappeared, loaded again"). Proof: `out/headed-frames2/f00.png` is the first captured frame and is complete; `shell_app_chrome.py` 17/17 |

| D-39 | **`navigator.getBattery()` is exposed to web content (ASTRA-0011).** Upstream marks the binding `ChromeOnly` to stop battery-status fingerprinting; the owner asked for it after `checkmydevice.app/battery-test` reported the API unsupported. The value is a browser hint (charge level / charging), never battery health. Reversible by dropping the patch or setting the pref false. | Decided 2026-11-04 (owner request). | D-40 | **Astra owns every yes/no page-permission prompt, not just geolocation and camera/microphone.** The `Integration.contentPermission` seam routes `desktop-notification`, `persistent-storage`, `xr`, `loopback-network` and `local-network` into the same `PagePermissionPrompt`, with one schema enum, host mapping and `SitePermissions` name each. Local-network grants keep the engine's temporary expiry and `notifyShown()` call. Picker-shaped and per-request prompts stay native on purpose because a yes/no card cannot answer them: `serial` (port chooser), `midi` (site-permission add-on install), WebRTC `screen`/`audioCapture` (source picker) and `storage-access` (no stored policy; the engine replies with a per-embedder choice). Those exceptions are recorded in `docs/astra/DIALOGS.md`, not silent fallbacks. | Decided 2026-11-04 (owner: "check almost all the permission output popups"). Live proof: `tools/perf/stress/permission_kinds_probe.py` (notifications allow/deny, persistent-storage allow/dismiss, native doorhanger absent) |
| D-41 | **Profile switching is an in-window space transition, not a profile-directory change.** A running Gecko process cannot change `ProfD`, and launching another instance violates the "same window" requirement. Each profile therefore browses in an Astra space backed by a Firefox container: switching activates that space in the current window, keeps the tabs of the profile left behind, and partitions cookies, sign-ins, localStorage/IndexedDB and the HTTP cache per `userContextId`. Preferences, extensions and the Places history database remain shared by the one running directory; the Profiles copy says so and `docs/astra/STATE.md` records the limit. The binding (profile id → space id) lives in `astra.profiles.spaces`; creating/deleting a profile creates/removes its space (and container data), and `space.switched` keeps the roster's `current` in step. | Decided 2026-11-07 (owner: "the profile that are there should be switchable in a window"). Live proof: `tools/marionette-probe/profiles-switch-probe.py` (same window/process, tabs restored, cookie + localStorage isolation) |
| D-42 | **Blocker = Brave `adblock-rust` in-tree engine + Astra-owned data and UI, not a sidecar and not a Brave-branded product.** The engine is the audited `adblock 0.12.1` crate Mozilla already vendors (one compiled instance shared by the channel hook and chrome). Rust owns matching, resources, cosmetics and counters; a thin C++ bridge keeps the pre-connect network hook and the XPCOM ABI; `nsIAstraBlockerService` is the JS management seam. The Host module owns the Brave-derived catalog, HTTPS fetch/cache, a 24 h default schedule and the settings prefs; a page actor injects CSS/scriptlets. Brave-owned list sources and `brave-*`/SugarCoat resources are dropped (no Brave rewards, telemetry, P3A or update hosts); every shipped list keeps its upstream URL and licence. Source of truth is `blocker/`; `forge overlay` stages it and `forge export` regenerates ASTRA-0003/0004/0005, so a Firefox bump re-stages rather than hand-editing the engine. `$redirect` body substitution and worker-thread compilation remain deferred and are recorded in `BLOCKER.md`. | Decided 2026-11-07 (owner: replace the blocker with the Brave engine, deeply integrate it in Rust, add settings/schedule and remove Brave branding/telemetry). Live proof: `tools/marionette-probe/blocker-probe.py` (155 226 rules, pre-connect cancel, cosmetic hide, settings, counters) |
