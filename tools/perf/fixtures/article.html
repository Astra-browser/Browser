Why local fixtures

Performance benchmarks must not touch the live web: no network variance, no flakiness, reproducible everywhere including CI sandboxes. This page stands in for a typical documentation article: headings, paragraphs, links, one table, one code block. Ten- and fifty-tab memory tests load this page with distinct query strings so each tab has its own history entry while sharing the cache.

Method notes

Startup is measured as process spawn to Marionette listen. Memory is summed VmRSS over the browser process group. Scroll cost is main-thread time for a scripted full-page sweep plus a rAF frame-delta probe. All numbers are medians of three runs on local fixtures only.
